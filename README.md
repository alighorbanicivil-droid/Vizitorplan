# راهنمای بازدیدکنندگان — نقشه‌ی محور

یک فایل مستقل (`index.html`) که پلان محور خیابان‌ها را نشان می‌دهد و با GPS گوشی موقعیت بازدیدکننده را روی پلان و در خیابان/کیلومتراژ مشخص می‌کند.

## انتشار روی GitHub Pages
1. در یک مخزن جدید (مثلاً `visitor-plan`) فایل `index.html` را آپلود کن.
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / root → Save.
3. آدرس نمایش داده شده (`https://<user>.github.io/visitor-plan/`) را برای ساخت QR کد استفاده کن.

## نکات
- GPS فقط روی HTTPS کار می‌کند؛ GitHub Pages این را دارد.
- موقعیت بازدیدکننده روی هیچ سروری ذخیره یا ارسال نمی‌شود.
- داده‌ی خیابان‌ها داخل `index.html` است (بخش `plan-data`). اگر پروژه تغییر کرد، فایل باید دوباره ساخته شود.
